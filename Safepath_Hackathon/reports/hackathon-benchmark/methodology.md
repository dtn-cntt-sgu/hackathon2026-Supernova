# Methodology

Run with Python from repository root; --quick=10 iterations/1 repeat, --full=100 iterations/3 independently constructed sessions, both use separate warmup; full mode measures100 model-only samples and20 production pipeline samples per repeat. ORT profiling is enabled during measurements and may add overhead. --offline performs no HTTP/DB operations. CPU2 threads is the benchmark configuration, not a production setting. Input images are private immutable copies of existing validated local source snapshots, not synthetic tensors. No input images are published. Model-only excludes tensor/image preprocessing; pipeline-file includes disk decode/validator/quality/ROI and deployment inference/postprocessing but excludes network/queue/overlay encoding. Pre/post statistics are single-forward diagnostics; production vehicle multiscale may execute multiple calls. Do not sum percentiles.

Flood IoU=TP/(TP+FP+FN); Dice=2TP/(2TP+FP+FN), precision=TP/(TP+FP), recall=TP/(TP+FN); global counts and per-image means are separate. Undefined zero-denominator results must not become perfect scores. Vehicle AP uses explicit IoU matching and score ordering; deployment confidence thresholds limit PR recall. Refer to dataset documentation for human annotation/provenance/split requirements. Missing labels produce NOT EVALUATED, not zero/perfect accuracy.

Route scenarios are independently stated tests, labelled fixtures and optional disposable real PostGIS. Latencies of tests include setup; route-service latency is measured separately in isolated k6 bursts (one iteration per VU at1/10/25), with external providers/workers disabled.50VU deferred on constrained host. Stop on errors/threshold breaches.

The full inference run retained300 model-only and60 pipeline-file samples per model. The source record includes initial tracked diff metadata and final tool-source hashes; the dirty tree means commitSHA alone is insufficient. Operational steps were rerun after safety/reporting fixes; inference timings were preserved, not manufactured or re-labelled as a new execution.
